# JavaScript Practice

This repository contains my JavaScript practice exercises focused on programming fundamentals, data structures, input validation, and basic application security concepts.

The goal of this project is to strengthen my JavaScript skills and apply secure coding practices through practical exercises.

## Exercises

| # | Exercise | Concepts |
|---|---|---|
| 1 | Get Season | Functions, conditional statements, input validation |
| 2 | Calculator | Functions, arithmetic operations, input validation, error handling |
| 3 | Array Average | Arrays, loops, mathematical operations, input validation |
| 4 | Student Averages | Objects, arrays, nested loops, data validation |
| 5 | Flight Management System | Objects, arrays, functions, CRUD operations, input validation, data handling |

## Key Learning Areas

- JavaScript fundamentals
- Functions and control flow
- Arrays and objects
- Loops and nested loops
- Input validation and error handling
- Working with structured data
- Basic application security and secure coding practices
